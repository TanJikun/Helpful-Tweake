# Helpful Tweake

基于 [MaLiLib](https://github.com/sakura-ryoko/malilib) 的客户端端 Minecraft 辅助模组，提供实用工具与优化。

## 依赖

Fabric API、MaLiLib

## 功能-工具

### 更好的自动跳跃

- **效果**：自动走上≤1.25格高的方块时不会损失速度。原版自动跳跃会触发真实跳跃导致减速，本功能改为直接抬脚迈上去，走过去时速度不变。
- **默认状态**：关闭
- **默认热键**：无
- **灵感来源**：[Accessible Step](https://github.com/SecretOnline/accessible-step)。本实现为基于相同原理的独立重写，未照搬原代码。

### 全局经验修补

- **效果**：拾取经验球时，背包里所有带经验修补且损坏的物品都会一起修复，不需要拿在手上。潜影盒等容器内的物品不受影响。
- **默认状态**：关闭
- **默认热键**：无
- **灵感来源**：[OverpoweredMending](https://modrinth.com/mod/overpoweredmending)

### 更好的不死图腾

- **效果**：受到致命伤害时，背包里所有不死图腾都有机会触发救命，不需要拿在手上。`/kill` 等强制伤害仍无法被图腾抵抗，与原版一致。
- **默认状态**：关闭
- **默认热键**：无
- **灵感来源**：[Totem Inventory](https://modrinth.com/mod/totem-inventory)

### 更好的攀爬

- **效果**：在梯子、藤蔓等可攀爬方块上时，根据视角方向改变攀爬速度。向下看会越爬越快，向上看会越爬越快。
- **默认状态**：关闭
- **默认热键**：无
- **灵感来源**：[better-climbing](https://github.com/artemisSystem/better-climbing)。速度阈值与分阶段计时数据参考该项目。

### 更好的船

- **效果**：开启后船只可以越过一定高度的障碍（如台阶、半砖）。在配置界面中点击功能左侧的 +/- 按钮可展开设置能越过的障碍高度格数。
- **默认状态**：关闭
- **默认热键**：无
- **灵感来源**：[Better Boat Movement](https://modrinth.com/mod/better-boat-movement)。

### 更好的耐久显示

- **效果**：在物品图标上显示剩余耐久数字，数字颜色与耐久条颜色一致。耐久满时不显示。数字过大时会自动缩写（如 1.5K、2.3M）。在配置界面中点击功能左侧的 +/- 按钮可展开"耐久附魔推算实际耐久"选项，开启后显示的数字会考虑耐久附魔的影响，估算实际还能使用多少次。使用缩写使得超模模组物品数字不会太长：
- | 范围 | 显示示例 |
  | --- | --- |
  | 1~999 | `999` |
  | 1.0K~999K | `1.9K`、`99.9K`、`999K` |
  | 1.0M~999M | `1.5M`、`99.9M`、`999M`（100万） |
  | 1.0B~999B | `1.0B`、`99.9B`、`999B`（10亿） |
  | 1.0T~999T | `1.0T`（万亿） |
  | 1.0Q+ | `1.0Q`（千万亿，`int` 上限 21.4亿约 2.1B） |
- **默认状态**：关闭
- **默认热键**：无
- **灵感来源**：[Durability101](https://modrinth.com/mod/durability101)（作者 RedHubble）。
