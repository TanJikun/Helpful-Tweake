# Helpful Tweake

基于 [MaLiLib](https://github.com/sakura-ryoko/malilib) 的客户端端 Minecraft 辅助模组，提供实用工具与优化。

## 依赖

必要依赖：[Fabric API](https://modrinth.com/mod/fabric-api)、[MaLiLib](https://modrinth.com/mod/malilib)

可选依赖：[模组菜单（modmenu）](https://modrinth.com/mod/mOgUt4GM)

## 功能-工具

### 更好的自动跳跃

- **效果**：自动走上≤1.25格高的方块时不会损失速度。原版自动跳跃会触发真实跳跃导致减速，本功能改为直接抬脚迈上去，走过去时速度不变。
- **默认状态**：关闭
- **默认热键**：无
- **灵感来源**：[Accessible Step](https://github.com/SecretOnline/accessible-step)。本实现为基于相同原理的独立重写，未照搬原代码。

### 全局经验修补

- **效果**：拾取经验球时，背包里所有带经验修补且损坏的物品都会一起修复，不需要拿在手上。潜影盒等容器内的物品不受影响。
- **默认状态**：关闭
- **默认热键**：无
- **灵感来源**：[OverpoweredMending](https://modrinth.com/mod/overpoweredmending)

### 更好的不死图腾

- **效果**：受到致命伤害时，背包里所有不死图腾都有机会触发救命，不需要拿在手上。`/kill` 等强制伤害仍无法被图腾抵抗，与原版一致。
- **默认状态**：关闭
- **默认热键**：无
- **灵感来源**：[Totem Inventory](https://modrinth.com/mod/totem-inventory)

### 更好的攀爬

- **效果**：在梯子、藤蔓等可攀爬方块上时，按住空格向上爬、按住 Shift 向下爬。视角越陡（朝上看或朝下看）爬得越快，视角水平时按键也有最小速度。同时按空格和 Shift 或都不按时遵循原版攀爬规则。
- **默认状态**：关闭
- **默认热键**：无
- **灵感来源**：[better-climbing](https://github.com/artemisSystem/better-climbing)。速度阈值参考该项目。

### 更好的船

- **效果**：开启后船只可以越过一定高度的障碍（如台阶、半砖）。在配置界面中点击功能左侧的 +/- 按钮可展开设置能越过的障碍高度格数。
- **默认状态**：关闭
- **默认热键**：无
- **灵感来源**：[Better Boat Movement](https://modrinth.com/mod/better-boat-movement)。

### 更好的耐久显示

- **效果**：在物品图标上显示剩余耐久数字，数字颜色与耐久条颜色一致。耐久满时不显示。数字过大时会自动缩写（如 1.5K、2.3M）。在配置界面中点击功能左侧的 +/- 按钮可展开"耐久附魔推算实际耐久"选项，开启后显示的数字会考虑耐久附魔的影响，估算实际还能使用多少次。使用缩写使得超模模组物品数字不会太长：
- | 范围      | 显示示例                                   |
  | --------- | ------------------------------------------ |
  | 1~999     | `999`                                      |
  | 1.0K~999K | `1.9K`、`99.9K`、`999K`                    |
  | 1.0M~999M | `1.5M`、`99.9M`、`999M`（100万）           |
  | 1.0B~999B | `1.0B`、`99.9B`、`999B`（10亿）            |
  | 1.0T~999T | `1.0T`（万亿）                             |
  | 1.0Q+     | `1.0Q`（千万亿，`int` 上限 21.4亿约 2.1B） |
- **默认状态**：关闭
- **默认热键**：无
- **灵感来源**：[Durability101](https://modrinth.com/mod/durability101)（作者 RedHubble）。

### 更方便的收获

- **效果**：右键点击成熟的作物即可一次性收获并自动补种，不需要先收再种。手持带时运附魔的物品时收获量会增加。背包里有对应种子时会自动消耗一颗补种，没有种子时只收获不补种。在配置界面中点击功能左侧的 +/- 按钮可展开更多选项：可以设置必须手持锄头才能收获、锄头收获时是否消耗耐久值（耐久附魔会正常生效），以及一个作物黑名单用于排除不想被此功能影响的作物。仅单机模式可用。
- **默认状态**：关闭
- **默认热键**：无
- **灵感来源**：[Harvest-With-Ease](https://modrinth.com/mod/harvest-with-ease)

### 盾牌状态显示

- **效果**：直接给手持的盾牌染色，一眼判断盾牌是否处于冷却禁用状态。绿色表示盾牌可用，红色表示盾牌正在冷却中（被斧头攻击破盾后禁用5秒）。支持第一人称和第三人称视角，同时支持自己和其他玩家的盾牌。自己的盾牌冷却状态由服务端同步，精确可信；其他玩家的盾牌冷却服务端不会同步，本模组通过检测举盾姿态变化（破盾时盾牌会被强制放下）并辅以破盾声音事件来推测冷却时间。
- **默认状态**：关闭
- **默认热键**：无
- **灵感来源**：[Shield Statuses](https://modrinth.com/mod/shield-statuses)

### 盔甲HUD

- **效果**：在屏幕上显示身上4件盔甲（头盔、胸甲、护腿、靴子）的图标和耐久信息，无需打开背包就能随时查看装备状态。位置可以在配置界面中调整：默认显示在快捷栏左侧，也可以切换到屏幕四角，或通过百分比自定义屏幕任意位置（横向和纵向都是 1%~100%，1% 接近左上角，100% 在右下角）。如果同时开启了"更好的耐久显示"，盔甲图标上会自动显示耐久数字。
- **默认状态**：关闭
- **默认热键**：无
- **灵感来源**：[uku's Armor HUD](https://modrinth.com/mod/ukus-armor-hud)

### 彩色选择框

- **效果**：将准心所对方块的线框选择框替换为彩虹色，颜色会随时间不断滚动变化，让选中方块更加醒目。
- **默认状态**：关闭
- **默认热键**：无

### 控制爬行

- **效果**：按下绑定的快捷键就能让玩家趴下进入爬行姿势，可以钻进一格高的空间。在配置界面中点击功能左侧的 +/- 按钮可展开"触发方式"选项：选择"按下"时只有按住按键才会趴下，松开按键后会按原版规则恢复站姿（如果当时还在一格高空间里，仍然保持爬行）；选择"切换"时按一下按键趴下，再按一下按键才会按原版规则恢复站姿。
- **默认状态**：无（本功能没有开关，只有绑定按键；绑定按键后即可生效）
- **默认热键**：无
- **局限性**：仅在单人游戏（含局域网房主自己）生效，多人联机或专用服务器不可用。原因是爬行需要服务器端认可玩家碰撞箱变化，本模组目前是纯客户端模组，故无法实现。
- **灵感来源**：[Crawl](https://modrinth.com/mod/crawl)

### 可视化经验值

- **效果**：在屏幕底部的经验条上方显示两行信息。第一行是当前等级的经验进度（如 3/7，表示这一等级已经获得 3 点经验，再获得 4 点就能升级）；第二行是玩家累计的总经验值。在配置界面中点击功能左侧的 +/- 按钮可展开"文字颜色"选项，自定义这两行文字的颜色。
- **默认状态**：关闭
- **默认热键**：无
- **灵感来源**：[exp-counter](https://modrinth.com/mod/exp-counter)

## 世吞运维助手

- **效果**：在指定的方块正上方额外显示一个旋转了45°的方块副本，让你在远处也能一眼定位到这些关键方块的位置。默认方块：宝库、试炼刷怪笼、黑曜石、哭泣的黑曜石、深层钻石矿、钻石矿、深层煤矿、深层绿宝石矿和远古残骸。另有其他子功能，详见下文
- **默认状态**：关闭
- **默认热键**：无

#### 清海带-世吞运维助手子功能

- **效果**：开启后，当你靠近海带且海带在投影模组的选区内时，自动帮你打掉选区内的海带，不需要你手动对准。会自动切换到快捷栏中没有耐久度的物品来破坏海带，如果所有物品都有耐久度则选耐久最多的那个。不会转动你的视角。需要安装[投影(Litematica)](https://modrinth.com/mod/litematica)才能使用，未安装时配置项显示为红色且无法开启。点击功能左侧的 +/- 按钮可设置自动清理的范围（海带与你横纵竖坐标差之和的最大值）。
- **默认状态**：关闭
- **默认热键**：无

#### 透明基岩-世吞运维助手子功能

- **效果**：开启后所有基岩方块都会变透明，被基岩挡住的方块会显示出来。例如一个3×3的基岩方块中心藏着石头，开启后基岩不可见，石头直接显示出来。
- **默认状态**：关闭
- **默认热键**：无
- **灵感来源**：[千昭Zerの材质包](https://www.bilibili.com/video/BV1E3jG6gEsZ)。本实现为独立重写，未照搬其实现方式。

## 功能-优化

### 加粗显示优化

- **效果**：使用高清字体包时，加粗文字会因原版的一像素偏移渲染而出现错位。开启后，加粗文字会自动切换到材质包中带 cu_ 前缀的粗体字体文件（如原字体为 my_font.ttf，粗体字体为 cu_my_font.ttf），并完全禁用原版的偏移渲染，使加粗文字的位置与常规文字完全一致。如果材质包没有提供 cu_ 前缀的粗体字体文件，则禁用原版加粗效果。如果没有材质包更改字体，则沿用原版逻辑。项目目录下的[等线字体包](./%E7%AD%89%E7%BA%BF%E5%AD%97%E4%BD%93%E5%8C%85)就是一个示例，加载了等线字体。
- **默认状态**：开启
- **默认热键**：无
